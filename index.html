Input format — how to paste 
Each question starts with Q: and has four options A) B) C) D).
Separate questions with a blank line (or just start the next Q:).

Optional per question:  Ans: A   → adds an answer key page.
Optional header line:   Title: My Test Paper
Bilingual: put Assamese in ( ) or after | on any line.

Example:
Q: Who was the first CM of Assam? (অসমৰ প্ৰথম মুখ্যমন্ত্ৰী কোন?)

B) Bishnuram Medhi
C) Bimala Prasad Chaliha
D) Sarat Chandra Singha
Ans: A
